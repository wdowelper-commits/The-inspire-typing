## 3. Language & Layout Selection

**Triggered by:** Clicking "Start Urdu Lessons" or switching language in nav/settings.

**Flow:**
1. If English → go directly to `/lessons/english`.
2. If Urdu → show layout picker modal/page:
   - Option A: Urdu Phonetic (InPage style)
   - Option B: Urdu Standard (Nastaliq)
   - Preference saved in `settingsStore` (localStorage).
3. Go to `/lessons/urdu-phonetic` or `/lessons/urdu-standard`.

## 4. Lessons Page (`/lessons`)

**URL Pattern:** `/lessons` (redirects to last selected language) or `/lessons/english` / `/lessons/urdu-phonetic` / `/lessons/urdu-standard`

**Layout:**
- Language tabs: English | Urdu Phonetic | Urdu Standard
- Lesson accordion list:
  - Lesson 1 ► 1.1 | 1.2 | 1.3
  - Lesson 2 ► 2.1 | 2.2 | 2.3
  - ... up to Lesson 12
- Each sub-lesson shows: completion status (✅ / ○), last WPM (if registered)
- Click any sub-lesson → go to `/lessons/:language/:lessonId`

**States:**
- Guest: All lessons accessible; no completion status shown
- Registered: Completion checkmarks, last WPM displayed per sub-lesson

## 5. Lesson Detail Page (`/lessons/:language/:lessonId`)

**URL Examples:**
- `/lessons/english/1-1`
- `/lessons/urdu-phonetic/3-2`
- `/lessons/urdu-standard/7-3`

**Page Layout:**
```
[ Language Badge ] [ Lesson Title: "Lesson 3.2" ] [ Settings Icon ]
─────────────────────────────────────────────────────────────────
[ Live Stats: WPM | CPM | Accuracy | Mistakes | Timer ]
─────────────────────────────────────────────────────────────────
[ Typing Area ]
  Target text shown — each character highlighted as:
  · Gray = not yet typed
  · Green = typed correctly
  · Red = typed incorrectly
  · Blue cursor = current position
  
  Input: hidden <input> captures keystrokes, or transparent overlay
─────────────────────────────────────────────────────────────────
[ On-Screen Keyboard ] [ Toggle Hide/Show ]
─────────────────────────────────────────────────────────────────
[ Restart ] [ Previous Lesson ] [ Next Lesson ]
```

**Flow:**
1. Page loads → text displayed, input focused automatically.
2. User starts typing → timer starts on first keystroke.
3. Each character evaluated live (correct/wrong).
4. On-screen keyboard highlights next key in real time.
5. Lesson complete when all text typed OR user clicks "Done".
6. **Result modal** appears:
   - Stats: WPM, CPM, Accuracy, Mistakes, Time
   - Guest: "Save your progress — Sign Up Free" prompt
   - Registered: Progress saved to DB; badge check runs; if badge earned → badge popup
   - Buttons: "Retry" | "Next Lesson" | "Back to Lessons"

**Error/Edge States:**
- If lesson text not found: "Lesson not found" with back button.
- If user navigates away mid-lesson: no data saved (warning modal for registered users).

## 6. Test Page (`/test`)

**Page Layout:**
```
[ Test Settings Bar ]
  Language: English | Urdu Phonetic | Urdu Standard
  Duration: 1min | 2min | 3min | 5min | 10min
  [ Start Test ] button
─────────────────────────────────────────────────────────────────
[ Live Stats: WPM | CPM | Accuracy | Mistakes ]
[ Timer: countdown ]
─────────────────────────────────────────────────────────────────
[ Typing Area ]
  Random paragraph shown
  Character-by-character highlight (green/red/gray)
  Backspace: tracked as mistake; already-submitted words cannot be edited
─────────────────────────────────────────────────────────────────
[ On-Screen Keyboard ] [ Toggle ]
─────────────────────────────────────────────────────────────────
[ Restart Test ]
```

**Flow:**
1. User selects language + duration → clicks "Start Test".
2. Random paragraph loaded for selected language.
3. Timer starts on first keystroke.
4. Test ends when timer hits 0.
5. **Result Screen** (replaces typing area):
   - Final WPM, CPM, Accuracy %, Mistakes, Characters typed
   - Performance badge: "Beginner" (< 20 WPM) / "Improving" (20–40) / "Good" (40–60) / "Fast" (60–80) / "Pro" (80+)
   - Guest: Prompt to sign up to save result + appear on leaderboard
   - Registered: Result saved; leaderboard position shown; certificate button if threshold met
   - Buttons: "Try Again" | "Change Duration" | "View Leaderboard"

**Test Rules (enforced by typing engine):**
- Backspace counts as a mistake.
- Once a word is submitted (spacebar), it cannot be edited.
- Pasting text is blocked.

## 9. Auth Flows

### Sign Up (`/signup`)
1. User enters display name + email + password.
2. OR clicks "Continue with Google" → Supabase Google OAuth.
3. Email confirmation sent (if email/password).
4. On confirm → redirected to dashboard.
5. `profiles` row created automatically via Supabase trigger.

### Login (`/login`)
1. Email + password OR Google.
2. On success → redirect to previous page (or `/dashboard`).
3. Wrong credentials → error message inline.

### Guest to Registered Conversion
- After completing any lesson/test as guest → modal: "Great job! Save your score and earn a certificate — Sign Up Free."
- Click "Sign Up" → `/signup` with return URL to current page.

### Password Reset
1. `/forgot-password` page: enter email → send reset email.
2. Email link → `/reset-password` page: enter new password.

## 10. Admin Flows (`/admin`)

### Admin Login
- Same login page; admin role check after login.
- If `profiles.user_role !== 'admin'` → redirect to home with "Access denied".

### Admin Dashboard
- Summary cards: Total users, New users (7d), Tests today, Lessons today.
- Quick links to User Manager, Lesson Manager, Badge Manager.

### User Manager (`/admin/users`)
- Table: ID, email, display name, join date, tests count, best WPM, role, status.
- Actions: Disable account, View details, Promote to admin (superadmin only).

### Lesson Manager (`/admin/lessons`)
- Accordion list of all lessons by language.
- Click lesson → edit text content inline.
- Save → updates `lesson_texts` table in Supabase.
- Add new sub-lesson / remove sub-lesson.

### Badge Manager (`/admin/badges`)
- List of all badge definitions.
- Edit: name, description, icon, trigger condition (WPM threshold, lessons count, etc.).

## 12. Empty, Loading & Error States

| State | Behavior |
|-------|----------|
| Loading (data fetch) | Skeleton loaders; never blank white |
| No test history | "No tests yet — take your first test!" with CTA |
| No badges earned | Badge grid shown grayed out with lock icon |
| Lesson not found | "Lesson not found" page with back CTA |
| Network error | Toast notification "Connection error — please retry" |
| Auth error | Inline error message on form |
| Admin unauthorized | Redirect to home with toast "Access denied" |
